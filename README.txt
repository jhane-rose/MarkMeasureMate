MEASUREMATE — ADAPTIVE MEASUREMENT CALCULATOR

OPEN IN VS CODE
1. Download and extract the ZIP.
2. Open the extracted adaptive_measurement_calculator folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. The calculator works offline; it has no external libraries or network requirements.

FILES
- index.html: page structure and labels
- style.css: black-and-red theme and responsive layout
- app.js: units, conversion factors, and calculations

SUPPORTED CATEGORIES
Length, time, mass, area, volume, speed, and temperature.

IMPORTANT
Addition/subtraction convert units within the selected category before calculating. Temperature subtraction returns a temperature difference. Multiplication/division currently operate on the entered numeric values and display the result in the chosen unit; they do not infer compound dimensions such as m × m = m².
